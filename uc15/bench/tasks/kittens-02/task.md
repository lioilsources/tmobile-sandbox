# Implement replay serialization and re-run (`Replay`, `RecordedGame`)

Package `fuse_core` (pure Dart). In `lib/src/replay/replay.dart` the methods of `Replay` and
`RecordedGame.apply` are stubs. A replay = setup (incl. seed) + command log; events are regenerated by
re-running the engine.

- `toJson()` → `{'format': 'fuse-replay', 'version': formatVersion, 'setup': setup.toJson(), 'commands': [...]}`.
- `Replay.fromJson` — `FormatException` when the format tag or version is missing/wrong or the version is
  newer than `formatVersion`; otherwise rebuild setup and commands (`GameSetup.fromJson`, `Command.fromJson`).
- `encode({bool pretty = false})` / `static decode(String)` — JSON string round trip (pretty = 2-space indent).
- `run({int? upTo})` — re-run the first `upTo` commands (all when null or larger) on a new `RecordedGame`.
- `RecordedGame.apply(command)` — apply via `GameEngine.apply`, append the command and the produced
  events, update the state, return the step.

Verify: `cd fuse_core && dart test`.
